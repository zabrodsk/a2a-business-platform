Co funguje

  • Agentem zahájená registrace, website ownership challenge, nezávislý lidský owner účet, auditní scopes, jednorázový credential exchange a bezpečná rotace/revokace.
  • Report a neměnné důkazy z běžného UI/API/MCP, citované typované návrhy, lidské odpovědi a aktivace přesné verze. Kritické neznámé a chybějící schopnosti blokují dotčené závazky.
  • Vlastní servisní identita + tenký Pneu MCP nad stejným HTTP backendem. Katalog, dostupnost, case/quote/approval read, nabídka/výjimka, checkout a omezená publikace; žádné lidské approval nástroje.
  • Idempotentní managed relay prostředek a per-firm A2A task DB, scoped inbox, lease generation/token/epoch, revokace po čekání, durable reply/outbox a stabilní IDs po pádu.
  • Karta na firemním well-known URL a přímý footer odkaz až po potřebných grantech, vazba na schválený rulebook, ETag/revalidace, po revoke/stale pravidlech skutečné stažení dynamické karty.
  • Majitelem připravené/potvrzené A → B se stejnými case, quote, mandátem a platným rozhodnutím. Nejisté externí přístupy/zápisy zůstávají pending; nativní admin heslo/sessions lze skutečně rotovat.
  • Přijatý native checkout přežije restart i handover bez nového intentu, nonce, inkasa či rezervace. Ověřeno s explicitní local_demo fault injection; provider zůstává autoritou pro skutečnou platbu.

První online přihlášení a lokální vývoj

Online testovací konzole je na pneu007-production.up.railway.app/handle. Legacy zůstává naplněný dummy daty. Upgrade zachovává dřívější schválený audit a existující objednávky/platby; nevytváří nový audit ani nový lidský owner účet. Samostatný fresh walkthrough používá novou DB. Provozovatel předává prvnímu člověku oddělený setup credential soukromě. Na serveru je v HANDLE_OWNER_SETUP_SECRET; není publikovaný v kódu, webu ani kartě. Bot jej nesmí dostat. Další postup: první den, audit, MCP/HTTP nástroje.

HANDORU_FRESH=true npm run start:system

Pro opravdu čistý průchod použijte nové LEGACY_DB_PATH a LEGACY_RELAY_DB_PATH. Fresh flag existující data nemaže. Produkce používá HTTPS a vlastní HANDLE_OWNER_SETUP_SECRET. Původní HANDORU názvy zůstávají kompatibilními aliasy.
