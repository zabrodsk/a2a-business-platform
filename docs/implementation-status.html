Výslovná omezení

  • MIP-003 adaptér je pro schválený sandbox s nakonfigurovaným buyer node, nikoli neomezený onboarding libovolných cizích peněženek. Purchaser identifier je omezen na formát podporovaný připnutou Payment Service verzí.
  • Wallet fee ceiling vyžaduje externě zajištěnou izolaci bez top-upů či jiných klientů; samotný konfigurační flag takové podmínky neprokazuje. Explicitní enable flag povoluje první test, neoznačuje jej za úspěšný.
  • Masumi on-chain payout může přijít až po provider deadlines; dvouminutové video jej nesmí předstírat. Fyzické přezutí není dokončením platebního jobu.
  • Oddělené DB případy neprokazují izolaci dlouhodobé paměti modelu. Žádná skutečná zákaznická data.
  • Legacy backend je nasazený v samostatném Railway projektu pneu007-business. HTTPS přihlášení, objednávka, kalendář, ICS, auditní zdroje a zachování booking ID po restartu prošly online kontrolou. Dřívější here.now odkaz nadále obsahuje plán. Zdroj kódu je veřejný GitHub repozitář zabrodsk/a2a-business-platform, větev main propojená s Railway autodeploy.
